# Código Proyecto Integrador - Grupo 02

## DESCRIPCIÓN
En este proyecto hemos desarrollado  un programa en MATLAB para el cálculo de rutas óptimas utilizando grafos. 
El objetivo principal era modelar un sistema de nodos y conexiones para encontrar caminos entre diferentes puntos.
Además hemos implementado una función de optimización, cuyos coeficientes se pueden modificar en cualquier momento y asi estudiar distintos escenarios.

## FUNCIONALIDAD
El código emplea algoritmos de grafos que permiten:
- Representar nodos y sus conexiones
- Calcular rutas óptimas entre distintos vertices
- Analizar caminos posibles dentro del sistema

## CÓMO EJECUTAR
1. Abrir MATLAB
2. Cargar el archivo `CodigoGrafosRutasUFV.m`
3. Ejecutar el script desde la consola o el editor
    -  Consultar el barrio o intercambiador de interés e introducir en la consola.
